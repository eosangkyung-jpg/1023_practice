오전 이론 10:10–10:25

검색은 파이썬, 그림은 브라우저

비유: 주방장과 서빙

장소를 찾는 일(검색, 주소↔좌표)은 파이썬이 내 컴퓨터에서 해요. 지도를 그리는 일은 지도를 보는 사람의 브라우저가 해요. 손으로 끌고 확대할 때마다 브라우저가 카카오에 그림 조각을 받아 오거든요.

두 개의 열쇠

비유: 금고 열쇠 vs 우리 집 현관 카드

REST API 키는 파이썬이 써요 → 어제처럼 .env 금고에 숨겨요. JavaScript 키는 브라우저로 내려가니 숨길 수 없어요 → 대신 카카오에 "이 키는 우리 집 주소에서만 켜진다"고 등록해서 지켜요. 남이 베껴 가도 자기 사이트에선 안 켜져요.

x는 가로, y는 세로

비유: 그래프의 x축·y축

카카오는 좌표를 x = 경도(127쯤), y = 위도(37쯤), 그것도 글자로 줘요. 그런데 지도에 찍을 땐 LatLng(위도, 경도) 순서예요. 뒤집으면 마커가 바다에 찍혀요 = 오늘의 대표 AI 실수. 서울은 (37, 127).

지도가 회색이면

비유: 현관 카드는 등록된 문에서만

① 카카오맵 사용 설정 OFF ② 도메인 미등록 — http://localhost:8000처럼 포트까지 ③ 더블클릭(file://)으로 열기 — 주소가 없어서 안 켜져요. 한 줄 정리: "켜고, 등록하고, 서버로 연다"

AI 답은 다른 출처로 확인한다

비유: 친구가 알려 준 맛집, 지도 앱에서 한 번 더

AI는 없는 가게를 그럴듯하게 지어내기도 하고, 주소를 틀리게 말하기도 해요. 오늘은 카카오 API가 그 "다른 출처"예요. ✅ 있음 · 🟡 주소 다름 · ❌ 못 찾음 → AI 실수율 몇 %? 단, ❌가 곧 가짜는 아니에요(폐업·다른 이름). 사람이 한 번 더.

판다스 = 파이썬 속 엑셀

비유: 클릭 서른 번을 기록으로

엑셀로 하면 필터·피벗 클릭 수십 번인 일을 판다스는 한 줄씩 코드로 남기며 해요. 내일 새 파일이 와도 실행 한 번이면 똑같이 정리돼요. 그리고 데이터를 보기 전에 분석하지 않아요 — 몇 줄인지, 어디가 비었는지부터.
